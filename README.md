# موقع منظمة بناة العراق

موقع ثابت (HTML/CSS/JS) بالعربية من اليمين لليسار، بلا اعتماد على ووردبريس أو قاعدة بيانات.

## التشغيل
افتح `index.html` في المتصفح، أو ارفع المجلد كاملًا إلى أي استضافة (أو GitHub Pages أو Cloudflare Pages).

## الصفحات
`index.html` الرئيسية · `about.html` من نحن والشفافية · `programs.html` البرامج · `news.html` الأخبار · `volunteer.html` التطوع · `donate.html` التبرع · `contact.html` التواصل

## ما يحتاج إكماله
- **وثائق الشفافية** في `about.html` (قسم `transparency`): شهادة التسجيل، التقرير السنوي، أسماء الهيئة الإدارية، التقارير المالية.
- **تفاصيل التحويل المصرفي**: تُرسل حاليًا عبر واتساب عند التبرع. لا تُجمع بيانات دفع في الموقع.
- **النماذج** (تبرع، تطوع، تواصل) تفتح واتساب برسالة جاهزة. لاستقبال الطلبات في بريد أو جدول، اربطها بخدمة نماذج مثل Formspree.
- **صور البرامج الطبية والأيتام**: تستخدم أيقونات حاليًا. أضف صورًا في `assets/img` عند توفرها.
- **أرقام الأثر** (عدد المنازل والسلال): لم تُدرج لعدم توفر أرقام مؤكدة.

## منشورات فيسبوك
- يعرض الموقع صفحة فيسبوك الرسمية عبر مكوّن Meta الرسمي في الرئيسية وصفحة الأخبار (يُحمّل عند الوصول إليه).
- لتضمين منشورات محددة (تعمل حتى لو لم يظهر مكوّن الصفحة): أضف رابط كل منشور عام إلى `data/posts.json` هكذا:
  `[{"embed":"https://www.facebook.com/iraqbuildersteam/posts/رقم_المنشور"}]`
- لعرض بطاقات منشورات بتصميم الموقع، أضف عناصر إلى `data/posts.json` بالشكل:
  `{"date":"2026-03-01","text":"نص المنشور","image":"assets/img/x.webp","url":"رابط المنشور"}`
- للتحديث التلقائي الكامل يُنصح بإضافة Smash Balloon إذا نُقل الموقع إلى ووردبريس.

## الإعدادات
أرقام التواصل وروابط التواصل الاجتماعي في `assets/js/config.js`.
